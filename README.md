# AI Assistant Functionality Test

Этот репозиторий создан для демонстрации возможностей AI-помощника по программированию.

## 🎯 Что здесь тестируется

### Работа с различными языками программирования
- **Python** - анализ данных, машинное обучение, автоматизация
- **JavaScript** - веб-разработка, DOM манипуляции
- **HTML/CSS** - создание интерфейсов
- **SQL** - работа с базами данных

### Функциональные возможности
- ✅ Создание проектов с нуля
- ✅ Редактирование и рефакторинг кода  
- ✅ Поиск и исправление ошибок
- ✅ Работа с файловой системой
- ✅ Выполнение команд в терминале
- ✅ Работа с Jupyter notebooks
- ✅ Анализ и оптимизация кода

## 📁 Структура проекта

```
ai-functionality-test/
├── README.md              # Документация проекта
├── requirements.txt       # Python зависимости
├── package.json          # Node.js зависимости
├── .gitignore            # Игнорируемые файлы
├── src/
│   ├── data_analysis.py  # Анализ данных на Python
│   ├── web_components.js # Веб-компоненты
│   └── utils.py          # Вспомогательные функции
├── web/
│   ├── index.html        # Демо веб-страница
│   └── styles.css        # Стили
├── notebooks/
│   └── demo.ipynb        # Jupyter notebook демо
└── tests/
    └── test_utils.py     # Тесты
```

## 🚀 Как использовать

1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить демо: `python src/data_analysis.py`
4. Открыть веб-демо: `web/index.html`
